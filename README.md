# Trang Web Cá Nhân - Bài Tập Buổi 1

Dự án trang web cá nhân cơ bản được xây dựng bằng HTML5 và CSS3 trong khuôn khổ môn học Lập trình Web.

## Nội dung thực hiện
- Xây dựng cấu trúc thư mục chuẩn cho website (`css/`, `js/`, `images/`).
- Tạo trang `index.html` giới thiệu bản thân và các liên kết mạng xã hội.
- Định dạng giao diện bằng `css/style.css` (font chữ, màu sắc tiêu đề, căn giữa, hover liên kết).
- Quản lý mã nguồn với Git và triển khai lên kho lưu trữ GitHub.

## Công nghệ sử dụng
- **HTML5**
- **CSS3**
- **Git & GitHub**
